Ajuda do IFBA OS

O IFBA OS é uma distribuição comunitária voltada ao contexto acadêmico. Não é uma distribuição oficial do IFBA.

Portais acadêmicos

Os atalhos abrem somente os sites públicos do SUAP e do AVA IFBA. O sistema não acessa contas, APIs privadas, notas ou atividades acadêmicas.

IFBA AI

O assistente é opcional. Abra o aplicativo IFBA AI para consultar as opções de configuração. Não há chave de API incluída nesta instalação.

Atualizações

Use Discover para consultar as atualizações disponíveis. Revise as alterações propostas antes de instalar. É necessária conexão com a internet.

Ferramentas educacionais

Esta instalação inclui Thonny para programação em Python, LibreOffice Writer para documentos e GCompris para atividades educativas. A disponibilidade e o desempenho dependem da arquitetura e dos recursos do computador.

Privacidade

O Welcome não pede senha, matrícula ou credenciais acadêmicas. Para rever a documentação local, consulte os arquivos instalados em /usr/share/doc/ifba-os/.

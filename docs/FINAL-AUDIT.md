## KDE migration runtime update — 2026-11-20

The Plasma build inputs target Ubuntu 26.04/Plasma 6.6 and include SDDM, Plasma sessions, KWin, KDE applications, NetworkManager, the supplied wallpaper, an IFBA dark color scheme, a native global-theme layout and the existing GTK assistant. ISO 0.2.0 reached the custom Plymouth image in the first observed boot; the later ISO 0.2.1 corrected SDDM's X11 session selection and is now visibly running the Plasma desktop in UTM.

The 0.2.1 UTM screenshot shows the supplied metallic wallpaper, AVA IFBA, IFBA AI and SUAP desktop shortcuts, and a single centered bottom panel with launcher, browser/file-manager/terminal launchers, system tray and clock. The panel is light rather than the intended IFBA dark treatment. The IFBA AI desktop shortcut was clicked, but no assistant window became visible; because UTM input semantics may not have delivered the click to the guest, this does not establish either success or a reproducible app failure. The app is not runtime-validated. Network state, Firefox, menu, audio, workspace count, persistence, guest build ID, SDDM/journal, graceful shutdown/reboot, scaling, accessibility and Wayland remain unverified.

Detailed immutable build identities, hashes, tests, and UTM observations are in `ISO-RELEASES.md`. The live ISO is still a prototype; visual desktop startup does not make the migration functionally complete.

## Correction pass — 2026-11-21

- NetworkManager configuration now replaces the same-named Ubuntu vendor drop-in, explicitly manages `type:ethernet`, uses interface-independent DHCP, and masks `systemd-networkd.service` and its socket. Calamares unpacks the full SquashFS into the target, so these files are part of the installed system source. The actual installed image has not been tested.
- IFBA AI now displays the window before attempting D-Bus connection, and offers a retry after service errors. `PYTHONPATH=ai python3 -m unittest discover -s tests -v` passed 95 tests with 2 target-image-only skips. This does not prove GTK renders or D-Bus activation succeeds in Plasma.
- Konsole packaging tests, build checks, Bash/Python/JavaScript syntax checks, and `git diff --check` passed. No visual or interactive terminal check occurred.
- The Plasma session setup uses separate one-time markers and recognizes users initialized by the earlier marker, preventing layout/wallpaper reapplication to customized users. The dock launcher uses a proportion-preserving crop of the institutional mark downloaded from the official DGCOM/IFBA marks page; the old placeholder asset is not used.
- The dock launcher now keeps Kickoff and adds grid favorites/all-apps views, real `.desktop` favorites, and native suspend/logout/reboot/shutdown actions. A packaged KRunner runner adds matching against installed application `Comment` fields; desktop names, generic names, and keywords remain handled by KDE's Services runner. CMake/CTest built the extension and passed its matcher test on Ubuntu 26.04 ARM64 and AMD64, and the desktop packaging suite passed 25 tests. No ISO was built; popup sizing, keyboard/mouse navigation, actual app launches, power actions, persistence, and rendered blur remain unverified in a guest.
- The top bar now includes an `org.ifbaos.controlcenter` QML plasmoid backed by KDE's NetworkManager, BlueZ, audio, PowerDevil, notification and MPRIS APIs. It gates Bluetooth, audio, brightness, battery and power-profile controls on reported availability and adds BlueZ, PipeWire Bluetooth, KScreen and power-profiles packages. The packaging suite passes 27 desktop tests; Qt's `qmlformat` parser accepts the QML. No ISO was built, and real service states, interaction, QML import resolution, appearance and blur remain unverified in Plasma/UTM.
- `utmctl list` returned macOS Automation `OSStatus -1743` and no VM entries from this session; no screenshot or guest diagnostic was captured. Host disk availability was 27 GiB, below the documented 30 GiB build requirement, so no ISO build was started. Previous VM observations still describe older images only.
- Documentation overlap review found the roadmap/audit summarize state while release, VM, technical, architecture and security documents preserve distinct evidence. No documents were deleted or historical outcomes rewritten.

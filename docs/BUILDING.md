# Building the prototype ISO

The ISO configuration targets Ubuntu 24.04 LTS amd64 and XFCE. It is a reproducible starting point, not a release pipeline. Package availability and licensing must be checked against the exact archive snapshot before distribution.

Requirements: Docker Desktop with at least 8 GB RAM, 30 GB free disk, and network access. From the repository root run `./scripts/build-iso.sh`. The host script invokes `scripts/build-iso-container.sh` and writes the ISO to `output/ifba-os-ubuntu-24.04-amd64.iso`. A persistent Docker volume named `ifba-os-build-cache` holds the Linux root filesystem because the macOS host filesystem is case-insensitive. Remove it with `docker volume rm ifba-os-build-cache` only when you want to discard the cached root filesystem. On Apple Silicon, amd64 emulation is required. Do not boot this image on real hardware as an installation image; it has no supported installer workflow.

The image is a live-session prototype, not an installer. It includes XFCE, LightDM with the GTK greeter, Xorg, `xinit`, NetworkManager, NetSurf, the local welcome-page prototype, the generated wallpaper, and the Ubuntu generic kernel. The `ubuntu` live user is configured for automatic login. Package selection remains a visual prototype and does not install applications. The container's resolver stub is removed before SquashFS creation so the guest can initialize its own systemd-resolved configuration. Never add credentials or personal data to the build context.
